# BlaBlaHelp

Coche compartido solidario entre Madrid, Castilla-La Mancha y Andalucía mientras la alta velocidad permanece interrumpida tras el accidente de Urda (28 de octubre de 2026). Sin ánimo de lucro, sin comisiones, sin teléfonos expuestos.

- `index.html`: la web completa, sin build. Despliégala tal cual en Vercel, Netlify o Cloudflare Pages.
- `schema.sql`: base de datos y reglas de seguridad para Supabase (ya aplicado al proyecto `BlaBlaHelp`).
- `SETUP.md`: guía de puesta en marcha y mantenimiento.

Para probar en local: `python3 -m http.server 8080` y abrir `http://localhost:8080`.
